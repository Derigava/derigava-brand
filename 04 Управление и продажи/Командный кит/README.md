# Командный кит

Внутренние материалы для своей команды: объявления в чат, итоги и рейтинги, обучающие слайды, инструкции, таблицы. Палитра — терминальная, общая с WORK: чёрный #0A0B0A и кислотный #B8FF2C (тема Terminal) или бумага #F3F5EF и тёмно-зелёный #3D6E00 (тема Paper, для печати).

| Путь | Что это |
|---|---|
| `brandbook.html` | Книга кита: основа, токены, голос, данные, форматы, живые образцы 16 компонентов и 7 форматов. Переключатель Terminal / Paper |
| `brandbook-terminal.pdf`, `brandbook-paper.pdf` | Та же книга в PDF |
| `previews/terminal`, `previews/paper` | PNG компонентов и шаблонов; форматы в реальном размере (1080×1080, 1080×1350, 1080×1920, 1920×1080) |
| `source` | Токены (`tokens.json`, `tokens.css`), компоненты (`components/bundle.css` + README и превью каждого), разделы о голосе, данных и форматах |
| `excel` | Навык `derigava-tables` и хелпер `derigava_xlsx.py` для таблиц .xlsx в обеих темах |

## Как пользоваться

- Картинка или слайд в HTML: подключите `source/tokens.css`, затем `source/components/bundle.css`, разметку берите из README компонента. Тема — `data-theme="dark"` или `"light"` на `<html>`.
- Быстрый пост без кода: возьмите PNG формата из `previews` как образец и повторите в своём редакторе.
- Таблица Excel: навык из `excel`.

Подпись на внутренних материалах — `derigava_█`. На том, что уходит клиентам или в общие каналы компании, подписи нет.

Публичные тексты об управлении и продажах (соцсети, статьи) берут макеты WORK из папки templates на уровень выше.

Шрифты подключаются из «00 Основа/assets/fonts» относительными путями: интернет не нужен, структуру папок сохраняйте. PNG и PDF кита перерисовывает `00 Основа/source/render_kit.py`.

Имена и продукты в примерах вымышлены.

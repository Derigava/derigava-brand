# Callout

Плашка, которая закрывает кадр: вывод, итог, главное правило. Обычная — на `acid-deep`, рисковая — в рамке `alert`.

## Разметка

```html
<div class="dt-callout">
  <span class="dt-label">&gt; ИТОГ</span>
  <p class="dt-callout__text">Одна фраза вывода.</p>
</div>

<div class="dt-callout dt-callout--alert">
  <span class="dt-label">[!] ВАЖНО</span>
  <p class="dt-callout__text">Что сломается, если не сделать.</p>
</div>
```

## Правила

- Одна плашка на кадр, внизу, перед подписью.
- Текст — одна-две строки, до ~120 знаков. Список внутрь не клади.
- Метка: `> ИТОГ`, `> ГЛАВНОЕ`, `> ЗАПОМНИ`; для риска — `[!] ВАЖНО`, `[!] НЕ ДЕЛАЙ`.
- Вместе с `CTA` на одном кадре не ставь — выбери одно.

# Голос и тексты

Пишем как тимлид, который уважает время команды: на «ты», коротко, по делу, с иронией над ситуацией и без неё над людьми.

## Тон

- **На «ты», глаголами.** «Закрываем неделю», «Звоним до 19:00», «Заполни отчёт». Не «Уважаемые коллеги, просим вас…».
- **Сначала что делать, потом почему.** Причина — одна фраза. Если без причины правило выглядит самодурством, причину пишем обязательно.
- **Ирония — да, пассивная агрессия — нет.** Шутим над процессом, CRM, понедельником. Не шутим над человеком, его результатом или ошибкой.
- **Без восклицательных знаков.** Энергию дают размер цифры и кислотный цвет, а не «!!!». Исключение — ни одного.
- **Без эмодзи.** Вместо них глифы: `▲` рост, `▼` падение, `●` статус/без изменений, `→` следующий шаг, `█` курсор, `[OK]` готово, `[!]` риск, `[+]`/`[–]` плюс/минус в сравнении.

## Словарь меток

Системные метки (`mono-label`) — ВЕРХНИМ РЕГИСТРОМ, с префиксом. Берём из этого списка, чтобы одна и та же вещь везде называлась одинаково.

| Ситуация | Метка |
|---|---|
| Новость, изменение правил | `> ОБЪЯВЛЕНИЕ`, `> ИЗМЕНЕНИЕ` |
| Напоминание, срок | `> НАПОМИНАНИЕ`, `[!] ДЕДЛАЙН`, `> СЕГОДНЯ` |
| Итоги | `> ИТОГИ ДНЯ`, `> ИТОГИ · НЕДЕЛЯ 42`, `> ИТОГИ · ОКТЯБРЬ` |
| Успех | `[OK] ПЛАН ЗАКРЫТ`, `[OK] РЕКОРД` |
| Поздравление | `> С ДНЁМ РОЖДЕНИЯ`, `> ГОД В КОМАНДЕ` |
| Обучение | `> ОБУЧЕНИЕ · МОДУЛЬ 03`, `> ВОЗРАЖЕНИЕ «ДОРОГО» · ШАГ 1` |
| Инструкция | `> ИНСТРУКЦИЯ · ОТЧЁТ` |
| Аргументы для звонка | `> АРГУМЕНТЫ · ТАРИФЫ` |
| Вывод, главное | `> ИТОГ`, `> ГЛАВНОЕ`, `> ЗАПОМНИ`, `> ЗАЧЕМ` |
| Пояснение | `// КАК ЧИТАТЬ`, `// ВАЖНО`, `// ИСТОЧНИК` |
| Запрет, риск | `[!] НЕ ДЕЛАЙ`, `[!] ВАЖНО`, `[!] СРОЧНО` |
| Скрытые данные | `// СКРЫТО` |

`[!] СРОЧНО` — только когда правда горит сегодня. Если каждую неделю что-то «срочно», метка перестаёт работать.

## Заголовки

Заголовок — действие или вывод, а не тема.

| Тип | Шаблон | Пример |
|---|---|---|
| Объявление | Что меняется — ключевое слово в `acid` | «С понедельника отчёт — **до 19:00**» |
| Напоминание | Глагол + сколько осталось | «Добиваем хвосты: **5 оплат** до плана» |
| Итоги | Цифра + подпись, заголовок не нужен | `112%` · «плана команды» |
| Обучение | Действие одним глаголом | «Сначала уточни, с чем сравнивают» |
| Аргументы | «Почему X выгоднее Y» | «Почему **пакет** выгоднее месяца» |
| Инструкция | «Как <действие>» | «Как заполнить **отчёт**» |
| Поздравление | Имя + 1–2 слова | «Алиса, огонь» |

- До 7 слов, до двух строк. Без точки в конце.
- В `acid` — одно слово или число, то, ради чего картинка.
- Кавычки — «ёлочки», внутри — „лапки“. Тире — длинное «—» с пробелами.

## Так / не так

| [OK] Так | [!] Не так | Почему |
|---|---|---|
| Заполни отчёт до 19:00 | Просьба всем своевременно заполнять отчёты | Конкретный срок вместо «своевременно» |
| Отчёт до 19:00, чтобы вечером разобрать спорные сделки | С понедельника отчёт до 19:00!!! | Причина вместо восклицаний |
| Неделя закрыта на 94%. Не хватило 3 оплат | Неделя провалена | Факт вместо оценки |
| Не успеваешь — напиши до 18:30 | Опоздания недопустимы | Выход из ситуации вместо угрозы |
| Алиса — 14 оплат, рекорд отдела | Алиса молодец, берите пример | Конкретный повод, без сравнения людей |
| 3 сделки без оплаты больше 5 дней | Некоторые до сих пор не дожали клиентов | Цифра вместо намёка на людей |

## Канцелярит → по-человечески

| Вместо | Пишем |
|---|---|
| осуществить звонок | позвонить |
| в целях повышения конверсии | чтобы больше оплат |
| данный тариф | этот тариф |
| в случае отсутствия | если нет |
| просьба ознакомиться | прочитай |
| производится оплата | клиент платит |
| на сегодняшний день | сейчас |

## Имена и люди

- В рейтингах и таблицах: имя + первая буква фамилии — «Алиса В.».
- В поздравлениях — имя, как его зовут в команде.
- Ошибки разбираем без имён: «в одной сделке на неделе…», а не «Глеб опять…». Имя в разборе — только с согласия человека.
- Скриншоты: ФИО, телефоны и почты клиентов закрываем плашкой `// СКРЫТО`.

## Даты, время, сокращения

- Дата: `23.10`, с годом — `23.10.2026`. День недели — заглавными сокращением: `ПТ · 23.10`.
- Время: `19:00`. Часовой пояс — `МСК` — пишем, когда время влияет на звонки или дедлайн.
- Диапазон: `12.10 — 18.10`, неделя — `НЕДЕЛЯ 42` или `Н42` (в подписях графиков).
- Сокращения единиц в шапках и подписях: `шт`, `₽`, `тыс`, `млн`, `п.п.` (процентные пункты), `%`. В тексте — полностью: «оплат», «рублей».
- Названия продуктов и тарифов — как в прайсе, с кавычками у собственных имён: Плюс, «Максимум».

## Длина

| Формат | Максимум |
|---|---|
| Сторис | 25 слов |
| Пост 1080×1080 | 60 слов |
| Пост 1080×1350 | 90 слов |
| Слайд-тезис | заголовок + 4 пункта по 12 слов |
| Пункт `Steps` | заголовок до 5 слов + 2 строки пояснения |
| Плашка `Callout` | 120 знаков |
| Метка | 40 знаков |

Не помещается — режь на две картинки, а не уменьшай шрифт.

# Личное

Замечать и оставаться собой. Повседневность · Мировоззрение · Опыт · Самоирония.

Разговорность, самоирония, честный незавершённый опыт. Не каждую заметку нужно превращать в урок. Личный текст не обязан доказывать продуктивность. Бытовая история может остаться бытовой историей.
